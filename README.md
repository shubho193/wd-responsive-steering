# Responsive Steering

Watch Dogs (2014) car handling mod. Gives quicker steering that adapts to speed, more grip, and drifts mainly from the handbrake.

## Install

1. Download the zip from [Releases](../../releases).
2. Extract `responsive_steering` into `Watch_Dogs\data_win64\mods\`.
3. Enable it in Nexus Tools.

## Build

1. Edit the values at the top of `src/build.py`.
2. Run:

```
python src/build.py "<Watch_Dogs folder>" [--gibbed "<Gibbed Tools folder>"]
```

This needs the Gibbed Disrupt tools.
